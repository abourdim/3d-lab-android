# 🧊 3D Lab — Android wrapper

Capacitor wrapper that packages the [3d-lab](https://github.com/abourdim/3d-lab) web app as an installable **Android APK**.

> مختبر ثلاثي الأبعاد · 3D Lab

Single-file 3D modeling playground for kids 7-14. 6 primitive shapes, SVG/DXF import, interactive electronics components, circuit wiring, gamified learning. Combines TinkerCAD-style creativity with video-game progression.

## Quick start

```bash
./manage.sh    # auto-detects your OS, then opens the menu
```

Build, test on emulator, and prepare a Play Store release from a single guided menu. See [WORKSHOP.html](WORKSHOP.html) for the full step-by-step guide.

## Download the latest APK

[📦 v1.0-debug release](https://github.com/abourdim/3d-lab-android/releases/latest) · [![QR](releases/download-qr.svg)](https://github.com/abourdim/3d-lab-android/releases/latest)

Scan the QR with an Android phone, or `adb install -r 3d-lab-v1.0-debug.apk`.

## Capabilities required at runtime

- Standard WebView (no special hardware)
